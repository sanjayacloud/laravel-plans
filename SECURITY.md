# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security issue, please email **sanjayacloudp@gmail.com** instead of opening a public GitHub issue.

Include:

- A description of the vulnerability
- Steps to reproduce
- Impact assessment, if known

We aim to acknowledge reports within 3 business days and will coordinate a fix and disclosure timeline with you.
